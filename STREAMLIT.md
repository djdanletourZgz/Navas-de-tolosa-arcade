# Despliegue en Streamlit Community Cloud

1. Entra en Streamlit Community Cloud e inicia sesión con GitHub.
2. Crea una nueva app desde este repositorio.
3. Selecciona la rama `feature/game-v1` para probar esta versión antes de fusionarla.
4. Archivo principal: `app.py`.
5. Pulsa Deploy.

El juego incluye controles de teclado y controles táctiles para móvil.
